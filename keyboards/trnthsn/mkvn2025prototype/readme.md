# MKVN2025 Prototype

A 3x4 macropad with rotary encoder and STM32F103 controller.

* Keyboard Maintainer: [Trnthsn](https://github.com/trnthsn)
* Hardware Supported: MKVN2025 Prototype
* Hardware Availability: [ThanhSon.Mech](https://www.facebook.com/ThanhSon.mech)

Make example for this keyboard:

    make trnthsn/mkvn2025prototype:via

Flashing example for this keyboard:

    make trnthsn/mkvn2025prototype:via:flash

## Bootloader

Enter the UF2 bootloader by holding the top-left key while plugging in the keyboard, pressing the physical reset button, or using the `QK_BOOT` keycode on layer 1.
