# MKVN2025

A 3x4 macropad with rotary encoder and STM32F072 controller.

* Keyboard Maintainer: [Trnthsn](https://github.com/trnthsn)
* Hardware Supported: MKVN2025
* Hardware Availability: [ThanhSon.Mech](https://www.facebook.com/ThanhSon.mech)

Make example for this keyboard:

    make trnthsn/mkvn2025:default

Flashing example for this keyboard:

    make trnthsn/mkvn2025:default:flash

## Bootloader

Enter the bootloader by holding the top-left key while plugging in the keyboard, pressing the physical reset button, or using the `QK_BOOT` keycode on layer 1.
